# Alerts and Detection Concepts

## Example Alert

```plaintext
Alert: Suspicious Miner Activity
Host: HR_02
User: chris
Process: cudominer.exe
Rule Match: miner
Severity: High
Classification: True Positive
```

## Why This Matters

Cryptomining activity inside corporate environments may indicate:

- Malware infection
- Unauthorized software execution
- Compromised endpoints
- Abuse of organizational resources
